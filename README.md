# CSC236 Summer 2026 Emergency Site

This folder contains a temporary emergency static course page for CSC236H1 Summer 2026.

Quercus is the official course site. This page is only a backup while Quercus is unavailable.

## Editing

Edit `index.html` directly for course information and schedule updates. The styling is in `style.css`.

Replace placeholder OneDrive/SharePoint links with UofT-login-protected links when they are available.

Do not place private course PDFs directly in this folder unless they are intended to be publicly accessible. Course files should remain in the UofT OneDrive/SharePoint folder and be linked from this page.

## Previewing locally

Open `index.html` in a web browser to preview the page locally. No build step, JavaScript, external libraries, or server is required.
